BLACKSITE: ASHEN PROTOCOL — a three.js tactical FPS set in Ashen Refinery, a decommissioned energy complex at dusk. 5v5 round-based combat (VANGUARD vs WRAITH): plant or defuse the energy charge at Reactor Site A or Cargo Site B, earn money each round, buy weapons between rounds, and outshoot bots that patrol, hold angles, flank, and react to what they see and hear. Five weapons (AR-7, VEX-9, BR-12, M-40, KX-45) plus a frag grenade, headshot damage, recoil and spread that punish firing on the move, and a fixed-step simulation kept apart from rendering. Runs fully offline from static files — no build step, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD move, mouse aim, LMB fire, RMB aim-down-sights, R reload, E plant/defuse, Q throw frag, B buy, M mute.
